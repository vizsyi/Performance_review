# Performance Review App

This is a full-stack web application for managing employee performance reviews. It demonstrates my skills in **React** (frontend) and **Node.js** (backend), and was developed as the **final exam project** for the _Software Development Tools and Methods_ course at **CUBIX**.

---

## 🚀 Features

- Manager-to-employee evaluations
- Dynamic frontend built with React
- RESTful API with Node.js

---

## 🛠 Tech Stack

- **Frontend**: React
- **Backend**: Node.js (Express), AWS Lambda (Function URL)
- **Storage**: AWS S3 (JSON file-based "NoSQL"-style storage)
